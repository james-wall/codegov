Know what AI wrote in your codebase

Open source CLI that scans git history and detects AI-authored commits. Zero configuration, works on any repository.

$ npx @james-wall/codegov scan
82.3% of commits are AI-authored (283/344)
Agents: 280 claude-code, 2 copilot, 1 cursor

How it works

Scan

Run the CLI once. Zero configuration required. Analyzes git metadata and commit messages to detect authorship patterns.

Attribute

Identifies a dozen AI tools — Claude Code, Cursor, Copilot, Devin, Aider, Codex, Gemini CLI, Jules, OpenHands, Sweep, JetBrains Junie, and Augment — with high precision.

Export

Generate detailed reports in HTML, CSV, or SBOM formats. Share with your team or integrate into tooling.

Detection signals

CodeGov matches against documented commit metadata patterns from each tool:

Tool Signals
Claude Code Co-Authored-By: Claude <noreply@anthropic.com>, Generated by Claude Code
Cursor cursoragent@cursor.com author, cursor[bot] author, Made-with: Cursor trailer
GitHub Copilot copilot@github.com co-author, copilot-swe-agent[bot] author, Agent-Logs-Url trailer
Devin devin-ai-integration[bot] author, bot@devin.ai author email
Aider aider (model) <aider@aider.chat> / <noreply@aider.chat> co-author
OpenAI Codex Codex <noreply@openai.com> co-author, codex[bot] / openai-codex[bot] author
Gemini CLI gemini-cli@users.noreply.github.com co-author
Google Jules google-labs-jules[bot] author
OpenHands openhands-agent author, openhands@all-hands.dev co-author
Sweep sweep-ai-deprecated[bot] / sweep-nightly[bot] author
JetBrains Junie jetbrains-junie[bot] author
Augment augmentcode[bot] author

Every signature is verified against real commits. Review-only bots that comment on PRs but never author commits (Amazon Q, gemini-code-assist, Cody) are deliberately excluded, and editor tools that commit under your own identity with no trailer (Windsurf, Continue, Cline, Zed, Tabnine) are unattributable from metadata — CodeGov counts only what it can verify.

Install & quickstart

CodeGov is a small Node.js CLI with a minimal dependency footprint — no native dependencies on the scan path. Install globally or run via npx.

Scan a repository
$ npx @james-wall/codegov scan
Generate HTML report
$ npx @james-wall/codegov export --format html
Export CSV for spreadsheets
$ npx @james-wall/codegov export --format csv -o report.csv
SPDX 2.3 compliance artifact
$ npx @james-wall/codegov export --format sbom -o provenance.json
Install globally
$ npm install -g @james-wall/codegov

See the GitHub repository for advanced options, configuration, and API documentation.
